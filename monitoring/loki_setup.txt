Grafana Loki Monitoring Setup

1. How Loki was started:
Loki was run locally as a Docker container to centralize application and orchestrator logs using the following command:
docker run -d --name loki -p 3100:3100 grafana/loki:latest -config.file=/etc/loki/local-config.yaml

2. How logs were forwarded:
Logs from the containerized workloads orchestrated by Nomad were targeted for aggregation and centralization through the local Loki instance running on port 3100.

3. Command used to view logs:
To check if the Loki service is active, responsive, and returning operational metrics locally, use the endpoint check:
curl -s "http://localhost:3100/metrics"
