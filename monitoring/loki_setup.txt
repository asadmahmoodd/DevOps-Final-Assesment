Loki Setup Notes:

1. Started Loki locally using the official Docker image with the following command:
   docker run -d --name loki -p 3100:3100 grafana/loki:latest

2. Configured log forwarding by running the hello-devops container with the Loki logging driver:
   docker run --log-driver=loki --log-opt loki-url="http://localhost:3100/loki/api/v1/push" hello-devops

3. Command used to view logs:
   docker logs loki
